# Satria Pro Folio

https://satriaportfolio.lovable.app

Ubah website ini dari satu halaman menjadi multi-halaman dengan React Router. Pertahankan gaya visual, warna, font, dan foto yang sudah ada.

Lakukan hanya ini:

1. Buat routing untuk: / (Beranda), /tentang, /layanan, /karya, /karya/:slug, /proses, /kontak, dan halaman 404. Halaman selain Beranda cukup berisi judul dan teks "Segera hadir" dulu.

2. Navbar sticky di semua halaman: Beranda, Tentang, Layanan, Karya, Proses, Kontak + tombol "Hubungi Saya". Menu hamburger di mobile, menu aktif ditandai.

3. Footer konsisten di semua halaman.

4. Semua tombol WhatsApp pakai https://wa.me/6285334814661?text=Halo%20Dian%2C%20aku%20mau%20diskusi%20soal%20website (bukan web.whatsapp.com, bukan phone=0).

5. Hapus semua placeholder: "[NAMA PROJEK 2]", "[NAMA PROJEK 3]", "[kategori]", "[EMAIL]", "[LINK]". Elemen yang datanya belum ada disembunyikan, bukan ditampilkan kosong. Di footer, hanya GitHub (https://github.com/SATRIA969) yang aktif.

6. Judul tab per halaman: "Nama Halaman — Dian Satria Utama | Web Developer Freelance", dengan meta description unik per halaman.

Jangan ubah isi section Beranda yang sudah ada selain poin 4 dan 5.
